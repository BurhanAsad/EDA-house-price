# House Price Exploratory Data Analysis

## Introduction

This project is about analysing house prices using Python. The main purpose is to understand how different factors affect the selling price of a house.

For this project, we have used the Ames Housing Dataset available on Kaggle.

## Objectives

- To understand the house price dataset.
- To check missing and duplicate values.
- To calculate mean, median, mode and other statistical values.
- To study the relationship between different variables.
- To find outliers using IQR and Z-score.
- To create different graphs for better understanding.
- To prepare a final dashboard.

## Dataset Details

- Dataset Name: Ames Housing Dataset
- Source: Kaggle
- Competition: House Prices - Advanced Regression Techniques
- File Used: train.csv
- Total Rows: 1460
- Total Columns: 81

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Google Colab

## Steps Performed

1. Imported the required Python libraries.
2. Loaded the dataset using Pandas.
3. Checked the shape and information of the dataset.
4. Checked missing values.
5. Separated numerical and categorical variables.
6. Performed descriptive statistical analysis.
7. Created histograms and boxplots.
8. Compared house prices according to quality and neighbourhood.
9. Calculated correlation and covariance.
10. Created scatter plots and a correlation heatmap.
11. Detected outliers using IQR and Z-score.
12. Checked duplicate values and data quality.
13. Handled missing values.
14. Created the final dashboard.

## Analysis Performed

In this project, we analysed different factors such as:

- Sale Price
- Overall Quality
- Living Area
- Lot Area
- Neighbourhood
- Basement Area
- Year Built

We also studied how these factors are related to the selling price of houses.

## Conclusion

Through this project, we learned how to perform Exploratory Data Analysis using Python. We understood how to clean data, calculate statistical values, find outliers and create different visualisations.

The analysis helped us understand the relationship between house features and their selling prices.
